# Локальное распознавание фото: эксперимент

Это отдельный сервис SmolVLM-256M + llama.cpp на CPU. Он получает **PNG-пиксели**
изображения и общий вопрос о видимом товаре. Название, категория и ожидаемый ответ
из архива в запрос не передаются. Поэтому тест проверяет работу с изображением,
а не пересказ предоставленного названия.

Это пока проверка пригодности локальной модели для конкретного VPS, а не
подключённое зрение действующего классификатора. Результаты не меняют предложения,
цены, ручные метки, веса или активную модель. Никакие автоматически сгенерированные
описания не объявляются истинными метками. До использования в поиске нужны замеры
и проверка качества на реальных предложениях, включая упаковки с мелким текстом.

## Что зафиксировано

- Модель: [ggml-org/SmolVLM-256M-Instruct-GGUF](https://huggingface.co/ggml-org/SmolVLM-256M-Instruct-GGUF),
  revision `b9e4379657e1450d04d02eec8e345667265b0a00`, лицензия Apache-2.0.
- Два Q8-файла: 175 054 528 + 103 769 856 байт. Это размеры файлов, не RAM при
  инференсе. Точные SHA256 и имена в `vision-models.json`; загрузчик проверяет оба.
- CPU-образ llama.cpp разрешается в digest в CI. Только после теста реального
  мультимодального инференса публикуется его копия
  `ghcr.io/ivzaislu/ha-angebote-checker:vision-COMMIT`. Для запуска укажите выданный
  после публикации `@sha256:…`; плавающие теги загрузчик не принимает.
- Конфигурация: 1 CPU, 512 MiB RAM, **768 MiB RAM+swap суммарно**, один слот,
  контекст 1536, максимум 96 выходных токенов. GPU не используется.
- Только `127.0.0.1:8081`; отдельный Compose-проект `angebote-vision`, без импорта
  приложения из `COMPOSE_FILE`. Каталог моделей монтируется только для чтения.
  Сервис не перезапускается автоматически после ошибки или OOM.

Официальные протоколы: [llama.cpp multimodal](https://github.com/ggml-org/llama.cpp/blob/master/docs/multimodal.md),
[Docker](https://github.com/ggml-org/llama.cpp/blob/master/docs/docker.md).

## Запуск на сервере

Понадобятся Python 3.10+, Docker и Compose; внешняя Python-библиотека не требуется.
Не запускайте одновременно обучение текстовой сети и этот эксперимент на VPS с
1 GiB RAM. Обработка по одной фотографии, без фонового обхода всего архива.

Из корня проекта после `git pull --ff-only`:

```bash
# Вставьте digest проверенного образа из сообщения о выпуске, не этот шаблон.
python3 deploy/vision.py prepare --image 'ghcr.io/ivzaislu/ha-angebote-checker@sha256:REPLACE'
python3 deploy/vision.py start
python3 deploy/vision.py bench --offer-id 25768762
python3 deploy/vision.py status
python3 deploy/vision.py stop
```

Файлы скачиваются один раз в `.vision/models` и сохраняются после остановки.
Подготовка идемпотентна. Новые файлы заменяют существующие только после проверки
SHA256. `.vision/vision.env` отдельно от основной `.env`, а команды принудительно
используют `deploy/compose.vision.yaml`, свой проект и только сервис `vision`.

По ID строится адрес немецкого CDN Marktguru. Сервер скачивает до 8 MiB, затем
отдельный кратковременный контейнер ffmpeg преобразует WebP/JPEG/PNG в PNG не более
384×384, сохраняя пропорции. Конвертер имеет лимит 128 MiB, 1 CPU, выключенную сеть
и не видит модели или БД. Модель получает картинку как `data:image/png;base64,…`.
Анализ и конвертация выполняются локально; исходное фото скачивается с CDN.

Можно проверить локальную фотографию вместо CDN:

```bash
python3 deploy/vision.py bench --image-file /path/to/product.jpg
```

## Результаты и ошибки

В консоли и `.vision/result-*.json` сохраняются ответ модели, время HTTP-инференса
(без скачивания/конвертации фото), SHA256 поданных PNG-пикселей, закреплённые модель
и runtime, лимиты контейнера, статус/OOM и cgroup `memory.current`, `memory.peak`,
`memory.swap.current`, `memory.events`, если хост использует cgroup v2. Значения
памяти относятся ко всему контейнеру, пик включает загрузку модели. На cgroup v1
эти показатели могут отсутствовать; дополнительно используйте `docker stats`.

```bash
python3 deploy/vision.py logs
free -h
docker stats --no-stream
```

При ошибке запуска или OOM сначала остановите эксперимент `python3 deploy/vision.py stop`.
Не увеличивайте лимиты автоматически на VPS с 1 GiB RAM. Ошибка скачивания фото
означает, что по нему инференс не проводился; попробуйте действующий ID или файл.
`finish_reason: length` означает обрезанный ответ. Описание маленькой модели может
быть ошибочным даже при успешном запросе. Проверяйте содержимое и читаемые надписи,
а не только отсутствие ошибок процесса.

CI проверяет реальные декодирование и мультимодальный запрос на цветной PNG-фикстуре
под лимитами сервиса. Это тест работоспособности протокола, **не оценка распознавания
товаров и не гарантия расхода памяти/скорости на пользовательском VPS**. Пять–десять
реальных фотографий, сопоставленных человеком с ответами, нужны до подключения
результатов к поиску или обучению.
